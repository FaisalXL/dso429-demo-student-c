# DSO 429 HW1 — demo student c

Proof-of-concept student repo for the **file-drop** submission model.

Each round, this repo gains `answers/round-NNNN.json`. Course staff poll this
repo on a schedule and record **when they first saw** each file — the timestamp
that counts is theirs, not this repo's, because a git commit date can be forged
with one environment variable.
